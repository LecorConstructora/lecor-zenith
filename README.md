# Lecor · Zenith

Sitio estático de presentación del proyecto residencial Zenith.

## Ver localmente

Abrí `index.html` en un navegador. No requiere instalación ni proceso de compilación.

## Estructura

- `index.html`: contenido de la página
- `styles.css`: estilos responsive
- `script.js`: menú móvil
- `assets/`: fotografías del proyecto y logo de Lecor
